# Cover Drilling Template

`cover_drill_template.pdf` is a printable A4 template; the SVG beside it is
the editable vector source. The left outline is for the outside/top of the
cover. Use the mirrored right outline when placing the paper inside the cover.

Print at 100% scale and verify the 20 mm scale bar before drilling. The sensor
position assumes a SparkFun-compatible APDS9960-M breakout, so confirm the
actual module geometry before making holes.

| Part | Suggested opening |
| --- | ---: |
| APDS-9960 sensor | 6 mm (dashed 8 mm clearance option) |
| WS2812 status LED | 3 mm |
